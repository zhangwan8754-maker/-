# 📈 记录本（单文件版）· 记录即反馈，斜率看得见

一个**单个 HTML 文件**就是完整应用：`记录表.html`。
给健身、学习、写作等任何想持续做的事用：**只用记录做反馈，不用感觉做反馈**——感觉在中段永远是"没进展"，记录才看得见斜率。

不装软件、不要服务器、零外部依赖（无任何网络请求，打开即用，实测千条记录冷启动 ~0.1 秒）。

---

## ⚡ 30 秒上手

1. 把 `记录表.html` 保存到电脑或手机
2. 浏览器打开（电脑双击；手机见下方）
3. 点「＋ 记一笔」：选类别 → 填**量**（30 分钟 / 800 字 / 5 组）→ 保存

每次改动**立即自动保存**，下次打开数据还在。

## 📊 复盘（可视化）

点「📊 复盘」页签：

- **四块指标**：当前连续天数 / 近 7 天总量 / **斜率（周环比 ±%）** / 累计总量
- **打卡热力图**：近 18 周，一眼看出中断和密度（GitHub 风格）
- **近 30 天趋势**：每日量的柱状图 + 7 日均线——中段感觉没进展时，看这条线的斜率
- **分类概览**：每个类别的连续、本周 vs 上周、斜率、累计

点上方类别筛选（健身/学习/写作），所有图表按该类别的**量**统计；没填数值的类别自动按**条数**统计。

## 🏷️ 类别与量

默认：`💪 健身|分钟`、`📚 学习|分钟`、`✍️ 写作|字`。
设置里每行一个 `名称|默认单位`，随意增改。选类别时单位自动带出。

## 💾 数据存在哪

| 层级 | 说明 |
|---|---|
| 浏览器本机存储 | 默认，零配置，断网可用 |
| 绑定本地 JSON 文件 | 电脑 Chrome/Edge：设置 → 绑定文件，改动自动写入；放坚果云/OneDrive 文件夹即自动云备份 |
| 手动导出 | 导出 JSON（可导入合并）/ 导出 CSV（Excel/WPS 直接开） |

## 🔄 多设备同步（手机 + 电脑）

设置 → 云同步，用你自己的 **Gitee 私有仓库**（国内快、免费）当同步盘：

1. gitee.com 新建**私有**仓库（勾「初始化仓库」）
2. 设置 → 私人令牌 → 生成（只勾 `projects`）
3. 每台设备打开页面，填同一套 用户名/仓库名/令牌 → 保存并同步

改动自动同步，**按条合并**：两台设备同时记也不会互相覆盖，删除同步且不会"复活"。也支持 GitHub。
令牌只存在你自己设备的浏览器里。

## 📱 手机怎么打开

微信把 `记录表.html` 发给自己 → 点开 → 右上角「…」→ **用浏览器打开** → 「添加到主屏幕」，以后像 App 一样点开。
同一台设备固定用同一个浏览器，数据才连续；换浏览器先导出再导入。

## 🗂️ 数据格式

`records.json`，人类可读：

```json
{
  "version": 2,
  "records": [
    { "id": "…", "date": "2026-07-17", "type": "💪 健身",
      "content": "胸+肩训练", "value": 40, "unit": "分钟",
      "createdAt": 1752700000000, "updatedAt": 1752700000000, "deleted": false }
  ]
}
```

合并规则：同 `id` 取 `updatedAt` 较新的；删除用 `deleted` 标记同步。

## ❓ 常见问题

- **打开慢吗？** 不慢。单文件零网络请求，同步和文件恢复都在首屏渲染后才后台执行；列表超过 100 条分页加载。
- **换浏览器/清缓存数据没了？** 数据在原浏览器里。绑定本地文件或配好云同步，任一即可保底。
- **同步失败？** 多半是令牌过期或仓库名拼错，点「☁️」重试；离线时先存本机，联网自动补。
- **之前的旧版记录还在吗？** 在。旧数据自动兼容显示，不会丢。
