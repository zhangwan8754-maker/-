⚙️ 设置 / 备份

📄 保存为本地文件（电脑端推荐）

绑定一个 JSON 文件后，每次改动会自动写入该文件。把文件放进坚果云 / OneDrive 等同步盘文件夹，就能自动多一份云备份。

☁️ 多设备同步（手机 + 电脑）

用你自己的 Gitee（国内快，推荐）或 GitHub 私有仓库当同步盘：每台设备打开本页面、填同一套配置，数据就会自动合并同步，谁也不会覆盖谁。

怎么获取这些配置？（点开看步骤）

Gitee（推荐）：
① 注册/登录 gitee.com → 右上角「+」新建仓库 → 勾选「私有」→ 勾选「初始化仓库(README)」→ 创建
② 头像 → 设置 → 左侧「私人令牌」→ 生成新令牌 → 只勾 projects → 提交 → 复制令牌
③ 回到这里：平台选 Gitee，「仓库主人」填你的 Gitee 用户名，「仓库名」填刚建的仓库名，粘贴令牌 → 保存并同步

GitHub：同理，建私有仓库；令牌在 Settings → Developer settings → Fine-grained tokens，只授权该仓库的 Contents: Read and write 权限。

⚠️ 令牌相当于钥匙，只保存在你自己设备的浏览器里，不要发给别人。

🏷️ 记录类型（每行一个，可自由增改）

💾 手动备份 / 恢复

不想配同步也行：导出 JSON 用微信传到另一台设备，再导入即可（导入是合并，不会覆盖）。导出 CSV 可用 Excel/WPS 打开。
