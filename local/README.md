# 📋 本地记录表（单文件版）· 手机电脑都能用

一个**单个 HTML 文件**就是完整应用：`记录表.html`。
不用装任何软件、不用服务器、不用小程序审核 —— 用浏览器打开就能记录，**关掉网也能用**。

> 定位：记录即反馈。你把想说的记下来，对方看到后在「回应/备注」里写想法，形成双向反馈。

---

## ⚡ 30 秒上手

1. 把 `记录表.html` 保存到电脑或手机
2. 用浏览器打开（电脑双击即可；手机见下方「手机怎么打开」）
3. 点「＋ 写一条记录」开始记录

每次改动都会**立即自动保存**（页面顶部会显示「✅ 已自动保存」），下次打开数据还在。

---

## 💾 数据存在哪？怎么变成「本地文件」？

| 层级 | 说明 |
|---|---|
| ① 浏览器本机存储 | 默认自动保存，零配置，断网可用 |
| ② 绑定本地 JSON 文件 | 电脑 Chrome/Edge：设置 → 「绑定本地文件」，之后每次改动**自动写入**该 JSON 文件。把它放进坚果云 / OneDrive 同步文件夹 = 自动多一份云备份 |
| ③ 手动导出 | 任何设备都能「导出 JSON / 导出 CSV」。CSV 可用 Excel / WPS 直接打开 |

---

## 🔄 多设备同步（手机 + 电脑互通）

打开页面 → **⚙️ 设置 → 云同步**，用你自己的 **Gitee 私有仓库**（国内快，免费）当同步盘：

1. 注册/登录 [gitee.com](https://gitee.com) → 新建仓库 → 勾选**私有** + 「初始化仓库」
2. 头像 → 设置 → **私人令牌** → 生成新令牌（只勾 `projects`）→ 复制
3. 每台设备打开 `记录表.html`，在设置里填同一套：平台 Gitee、你的用户名、仓库名、令牌 → 「保存并同步」

之后：改动会**自动同步**（也可点「☁️ 立即同步」）。两台设备各自新增/修改会**按条智能合并**，谁也不会覆盖谁；删除也会同步。也支持 GitHub（配置方式在设置面板里有说明）。

> 🔑 令牌只保存在你自己设备的浏览器里，不会上传到别处；仓库是私有的，只有你们能看。

**不想配同步？** 也可以纯手动：A 设备「导出 JSON」→ 微信发给 B → B「导入 JSON（合并）」。导入是合并不是覆盖，放心操作。

## 📱 手机怎么打开 HTML 文件

- **微信传文件**：把 `记录表.html` 发到微信 → 点开 → 右上角「…」→ **用其他应用/浏览器打开**（推荐 Chrome / Safari / Edge）。打开后可「添加到主屏幕」，以后像 App 一样点开。
- 或放进手机的文件管理器，用浏览器的「打开文件」访问。
- 配好云同步后，手机上的改动和电脑实时互通。

> ⚠️ 注意：同一台设备上要**固定用同一个浏览器**打开，数据才连续（浏览器本机存储互不相通）。换浏览器时先导出再导入即可。

## 🗂️ 记录表字段设计

| 字段 | 说明 |
|---|---|
| 日期 | 记录属于哪天（默认今天，可改） |
| 类型 | 💛感谢 / 💗甜蜜 / 🌧️在意 / ⭐希望 / 📖日常 / 😊心情，**可在设置里自由增改** |
| 内容 | 想记录、想反馈的话（核心） |
| 心情 | 1–5 星打分，可不选 |
| 回应/备注 | 对方看到后写想法，形成反馈闭环 |

数据文件是人类可读的 JSON（`records.json`），格式：

```json
{
  "version": 1,
  "records": [
    { "id": "…", "date": "2026-07-16", "type": "💛 感谢",
      "content": "今天谢谢你……", "rating": 5, "note": "看到啦❤️",
      "createdAt": 1752600000000, "updatedAt": 1752600000000, "deleted": false }
  ]
}
```

- 同步合并规则：同一条记录（同 `id`）以 `updatedAt` 较新的为准；删除通过 `deleted` 标记同步，不会“复活”。

## ❓ 常见问题

- **换了浏览器/清了缓存，记录没了？** 数据在原浏览器的本机存储里。养成习惯：绑定本地文件或配置云同步，任一即可保底。
- **同步失败？** 多半是令牌过期或仓库名拼错；点「☁️」状态可重试。离线时会先存本机，联网后自动补同步。
- **两个人同时写会冲突吗？** 不会。按条合并 + 冲突自动重试，两边的内容都会保留。
- **想用 Excel 看？** 设置 → 导出 CSV。
