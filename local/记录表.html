📄 保存为本地文件（电脑端推荐）

绑定一个 JSON 文件后，每次改动自动写入该文件。放进坚果云 / OneDrive 同步文件夹 = 自动云备份。

☁️ 多设备同步（手机 + 电脑）

用你自己的 Gitee（国内快）或 GitHub 私有仓库当同步盘：每台设备填同一套配置，数据自动按条合并，互不覆盖。

怎么获取这些配置？（点开看步骤）

Gitee（推荐）：
① 注册/登录 gitee.com → 右上角「+」新建仓库 → 勾选「私有」+「初始化仓库(README)」→ 创建
② 头像 → 设置 → 「私人令牌」→ 生成新令牌 → 只勾 projects → 复制令牌
③ 回到这里：平台选 Gitee，填你的用户名、仓库名，粘贴令牌 → 保存并同步

GitHub：同理建私有仓库；令牌在 Settings → Developer settings → Fine-grained tokens，只授权该仓库 Contents: Read and write。

⚠️ 令牌相当于钥匙，只保存在你自己设备的浏览器里，不要发给别人。

💾 手动备份 / 恢复

导出 JSON 可传到别的设备导入合并（不会覆盖）；导出 CSV 可用 Excel / WPS 打开。
